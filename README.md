# 今日事今日毕

一天一张清单。没做完的自动结转并累计天数，拖过 5 天就劝你删掉，做完的按日期记进「回顾」。

**→ <https://halloyooo.github.io/jinrishi-jinribi/>**

单文件网页 App，没有后端、没有账号、不联网。数据只存在你自己浏览器的 localStorage 里。

## 装到 iPhone 主屏

必须用 **Safari**（微信内置浏览器和 iOS Chrome 装出来只是书签）：打开上面的链接 → 底部「分享」→「添加到主屏幕」。装完从主屏图标打开是全屏的，断网也能用。

## 规则

| 规则 | 说明 |
|---|---|
| 一天一张纸 | 没有分类、标签、优先级、提醒。单位是「天」，不是项目 |
| 结转全自动 | 打开就结算昨天，未完成的自己滚过来，不用手动认领 |
| 按真实天数累加 | 隔 3 天没打开就 +3 天，不是 +1——只加 1 等于奖励你不打开 |
| 拖过 5 天劝删 | 第 6 天起这条事下面出现「删掉它 / 再留一天」。留一天只压一天 |
| 凌晨 4 点换日 | 熬到 1 点打勾，仍算前一天的事 |
| 回顾只记做完的 | 按日期分组，不显示几点、不做统计图表。删掉的事不留痕 |

## 数据

键名 `jinrishi-jinribi.v1`，纯本地。**没有导出功能**：删掉主屏 App、清除网站数据或换手机，记录就没了。

装到主屏的 App 不受 Safari「7 天不互动清存储」规则约束（[WebKit 官方说明](https://webkit.org/blog/10218/full-third-party-cookie-blocking-and-more/)），正常用着就一直在。

## 文件

`index.html` 是整个 App（结构 + 样式 + 逻辑）。其余是 PWA 装机要的：`app.webmanifest`、`sw.js`、图标。
